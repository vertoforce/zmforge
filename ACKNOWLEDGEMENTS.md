# Acknowledgements

zmforge owes its start to [hetri-courses/mcp-radiant](https://github.com/hetri-courses/mcp-radiant),
an earlier project for building Black Ops III zombies maps with Claude.
zmforge was written from a specification based on its findings; none of
its code is used here.

Some facts about the mod tools in our docs were first reported by
[McReaper/t7_companion](https://github.com/McReaper/t7_companion) (MIT), a
knowledge base and toolkit for Black Ops III mod tools. We restated them in
our own words and checked them against our own install where we could; none
of its code or text is used here.
